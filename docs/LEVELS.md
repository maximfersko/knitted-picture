# Как делать уровни

Руководство для тех, кто добавляет или правит уровни «Вязаной картинки». Уровень пишется вручную только как рисунок и пара чисел. Поле клубков и сложность собирает генератор, а решатель и боты проверяют, что уровень проходим и не слишком лёгкий.

## Коротко: новый уровень за 10 минут

1. Скопируй ближайший по сложности исходник из `levels-src/` (шаблоны ниже) в `levels-src/level_NNN.json` с новым `id`.
2. Нарисуй картинку буквами в `picture`, задай цвета в `palette`, фон отметь в `fabric`.
3. Выбери механики уровня: 1–2 «главные» и остальное из шаблона.
4. Собери только его: `dotnet run --project dotnet/KnittedPicture.LevelTool -c Release -- --only NNN`.
5. Посмотри строку таблицы. Если стоит `!` или метрики вне коридоров, поправь параметры (см. «Что крутить») и пересобери.
6. Если уровень открывает новую коллекцию, добавь её в `Assets/Scripts/Core/Meta/Collections.cs`.
7. Пересобери все уровни без `--only`, прогони тесты (`dotnet test dotnet/KnittedPicture.Core.Tests`), закоммить и `levels-src`, и `Assets/Resources/Levels`.

## Где что лежит

| Путь | Что это |
|---|---|
| `levels-src/level_NNN.json` | Исходник: картинка, палитра, параметры. Правится руками |
| `Assets/Resources/Levels/level_NNN.json` | Готовый уровень для игры. Пишет генератор, руками не правится |
| `dotnet/KnittedPicture.LevelTool` | Генератор, боты, метрики |
| `Assets/Scripts/Core/Meta/Collections.cs` | Коллекции альбома: по 5 уровней под названием |
| `docs/GDD.md` | Таблица всех уровней и общие правила игры |
| `tools/levels/pictures.py` | Рисунки уровней 16–50 в одном месте (Python) |
| `tools/levels/designs.py` | Из рисунков и таблицы механик пишет исходники 16–50 |

### Уровни 16–50: Python-скрипты

Исходники уровней 16–50 не правятся руками по одному: они собираются скриптами в `tools/levels/`. Так все рисунки видны рядом, а параметры считаются по одной кривой сложности.

- `pictures.py` — словарь `P`: номер уровня → (название, палитра, ряды картинки). Запуск без аргументов проверяет ширину рядов, буквы палитры и печатает, сколько петель в каждом рисунке.
- `designs.py` — таблица `M` с механиками каждого уровня и функция `tier()` с общими параметрами этапа (потолок «наугад», чужая и лишняя пряжа, золото, перестановки). Число клубков считается от числа петель, время моли тоже.

```bash
python3 tools/levels/pictures.py          # проверить рисунки
python3 tools/levels/designs.py           # переписать levels-src/level_016..050.json
python3 tools/levels/designs.py 23 24     # только уровни 23 и 24
dotnet run --project dotnet/KnittedPicture.LevelTool -c Release -- --only 16-50
```

Скрипт перезаписывает исходник целиком. Если что-то поправили прямо в `levels-src/level_0NN.json`, перенесите правку в `P` или `M`, иначе она пропадёт при следующем запуске. Уровни 1–15 правятся прямо в JSON.

Новые уровни дальше 50 удобно добавлять так же: рисунок в `P`, строка в `M`.

Сборка детерминирована: одинаковые исходники всегда дают одинаковые уровни. CI проверяет, что `Assets/Resources/Levels` совпадает с `levels-src`. Поэтому после правки исходника уровни нужно пересобрать и закоммитить.

```json

  "timeLimit": 0,
  "palette": [
    { "key": ".", "hex": "#CDEBFF" },
    { "key": "o", "hex": "#FF9A3C" },
    { "key": "w", "hex": "#FFFFFF" }
  ],
  "picture": [
    "....ooo.....",
    "..oowwoo...."
  ],
  "fabric": ".",
  "band": 2,
  "mystery": false,
  "gold": 3,
  "slots": 4,
  "columns": 5,
  "spools": 10,
  "swaps": 4,
  "hidden": 3, "knots": 2, "links": 0, "locks": 0,
  "rainbow": 0, "thick": 0, "ice": 0,
  "extra": 2, "junk": 2,
```

### Картинка и цвета

| Поле | Что задаёт | Советы |
|---|---|---|
| `palette` | Буква → цвет. Порядок задаёт индексы цветов | Только цвета набора клубков (ниже), каждый не больше одного раза. До 10 цветов. Первым ставь цвет ткани: на экране победы он станет цветом пялец |
| `picture` | Ряды сверху вниз, все одной длины | Ширина 8–16, высота 6–16. Больше 16 не помещается на экран |
| `fabric` | Буквы ткани-основы: эти клетки связаны с начала | Обычно одна буква фона, например `.`. Можно несколько: `"sg"` — небо и трава |
| `mystery` | Скрыть эскиз: видны только фронт и силуэт | 1–2 раза на коллекцию |
| `gold` | Сколько золотых петель разбросать | 3–5. Генератор ставит их в разных рядах |
| `name`, `tip` | Название в альбоме и подсказка на старте | Подсказка — одна строка, без длинного тире, только когда уровень вводит новое |

### Поле клубков

| Поле | Что задаёт | Обычно |
|---|---|---|
| `slots` | Слотов на станке | 4; 3 — для сложных |
| `columns` | Колонок клубков на поле | 3–4 в начале, 5 дальше |
| `spools` | Сколько клубков нарезать | Петель рисунка ÷ 6 (от 10 до 24) |
| `swaps` | Перестановок соседних клубков: путают очередь | 2–7 |
| `band` | Натяжение полотна: на сколько рядов фронт может обогнать самый нижний | 2 с уровня 4; 0 — без ограничения |
| `playBand` | Натяжение в игре, если оно мягче, чем при нарезке клубков: раскладка та же, столбцам свободнее. Смягчить один уровень, не теряя его раскладку | 0 — как `band`; у 14-го — 3 |

### Механики

| Поле | Механика | Как работает |
|---|---|---|
| `hidden` | Скрытые «?» | Цвет виден, когда клубок впереди |
| `knots` | Узелки | Первый тап развязывает, второй отправляет |
| `links` | Связки | Едут парой, нужно 2 свободных слота |
| `locks` | Замки (ключ генератор ставит сам) | Открываются, когда ключ встаёт на станок |
| `rainbow` | Радужные | Вяжут любой цвет на фронте |
| `thick` | Толстые | 2 слота, 2 петли за шаг |
| `ice` | Ледяные | Тают от петель своего цвета; генератор ставит лёд так, чтобы он успевал растаять |
| `extra` | Лишняя пряжа | Клубки сверх рисунка: их можно не брать |
| `junk` | Чужая пряжа (цвета ткани) | На станке занимает слот насовсем. Главное наказание за тап наугад |
| `timeLimit` | Моль, секунды | Чтобы моль была финишным рывком, а не декорацией: игрок, который думает над ходом 2 с, заканчивает с запасом около 30%, а медленный (2,5 с) почти всегда успевает. Считается симуляцией в реальном времени, на глаз ≈ тапы решения × 2,8 с. На первой моли (17) запас больше |
| `hard` | Сложный уровень | Красная плашка, награда ×2 |

### Сложность и проверки

| Поле | Что значит |
|---|---|
| `minWin`..`maxWin` | Доля побед бота «средний игрок» из 200 партий |
| `maxRandom` | Потолок побед игрока, который тапает наугад |
| `maxForced` | Потолок доли ходов «без выбора» (полезный клубок только один) |
| `minDanger`..`maxDanger` | Доля «роковых» ходов, после которых уровень уже не пройти |
| `minFollower`..`maxFollower` | Победы игрока «по подсветке» (всегда берёт клубок, которому сразу есть работа). Обычные уровни: `minFollower` 0,7. Сложные: `maxFollower` 0,4 |
| `minSkilled`..`maxSkilled` | Победы игрока, который знает приёмы: короткие клубки первыми, узелки заранее. Сложные: 0,2..0,6 — без «стен» и без уровней на один трюк |
| `maxEarlyJam` | Потолок доли партий «среднего игрока», оборванных затором раньше трети картинки. Ранний проигрыш ощущается лотереей, поздний — «почти!». Обычно 0,25 |
| `seed` | С какого сида начинать поиск. Обычно `id × 10 + 1` |

## Как работает генератор

1. Картинка вяжется по правилам игры: берётся цвет с фронта, клубок набирает петли, пока не наберёт длину или цвет не кончится на фронте. Так нарезаются клубки, и этот порядок проходим даже с одним слотом.
2. Клубки раскладываются по колонкам в этом порядке. Затем соседние переставляются (`swaps`), добавляются лишняя и чужая пряжа и особые клубки.
3. Решатель проверяет, что уровень проходим без бустеров.
4. Боты играют по 200 партий: «средний игрок» (чаще берёт нужное) и «наугад».
5. Для подходящих вариантов считаются метрики решений.
6. Выбирается первый сид, где всё в коридорах. Если такого нет за 400 сидов, берётся ближайший, и в таблице ставится `!`.

## Как читать таблицу

```
id  название   размер петли цв клуб кол сл тапы  бот  наугад ранний подсв приёмы фронт выбор1 роковые  сид   механики
21  Рыбка      12×8      51  6   14   5  4   14   62%   12%     3%   99%   100%   2.1   38%    11%    213   канва ...
```

| Колонка | Хорошо | Плохо |
|---|---|---|
| `петли` | 40–150 | < 30 — уровень на полминуты; > 160 — затянуто |
| `бот` | В коридоре `minWin..maxWin`. `!` — не попал | 90%+ на среднем уровне, < 10% на обычном |
| `наугад` | < 25% с уровня 4, < 10% на сложных | > 40% — можно пройти не думая |
| `ранний` | < 25% партий | > 35% — уровень проигрывается на первых ходах |
| `подсв` | Обычный ≥ 70%, сложный ≤ 40% | Обычный < 50% — честная игра проигрывает, уровень кажется нечестным |
| `приёмы` | Сложный 20–60% | 0–10% — «стена»; > 80% — сложный только на вид |
| `фронт` | 1,8–2,8 цвета на фронте | < 1,5 — выбора нет |
| `выбор1` | < 50% ходов без выбора | > 60% — уровень «играет сам» |
| `роковые` | 5–25% | 0% — ошибки не наказываются; > 35% — злой уровень |

## Что крутить

| Симптом | Что сделать |
|---|---|
| Бот выигрывает слишком часто | `slots` −1, `swaps` +2, `junk` +1, `band` 2, больше клубков (`spools` +2) |
| Бот выигрывает слишком редко (0–5%) | Сначала `junk` до 1 или 0, потом `slots` по числу цветов, `band` 3, `swaps` −2, меньше замков, `rainbow` +1 |
| «Наугад» слишком высокий | `junk` +1, `band` 2, меньше слотов, `extra` +1 |
| Мало цветов на фронте, много ходов без выбора | Узор в рисунке: полоски, крапинки, блики разных цветов. Однотонные пятна — главный враг выбора |
| Роковых 0% | Меньше слотов, больше чужой пряжи, рисунок «слоями» (цвет, нужный только наверху) |
| Роковых > 35% | Больше слотов, меньше чужой пряжи, `rainbow` +1 |
| «Стена»: приёмы не помогают (< 20%) | Другой `seed`, `junk` −1 или `slots` +1; толстые и лёд чаще всего делают уровень «стеной» |
| Сложный на один трюк (приёмы > 60%) | Другой `seed`, `swaps` +1, `band` 2 |
| Много ранних заторов | `maxEarlyJam` 0,25 и другой `seed`; если не выходит — `swaps` −1, `junk` −1 или `slots` +1, а сложность вернуть узором наверху картинки |
| «не нашлось решаемого поля» | Слишком много замков, связок или льда для такого поля. Уменьши их или добавь слот |
| Долго считается | Почти всегда это уровень вне коридоров: генератор перебирает все 400 сидов. Смотри прогресс в выводе (`[12/50] уровень … — 190 с`) и сначала добейся коридора по боту. Ещё проверь `spools` (≤ 24) и размер (≤ 16×16) |

Если уровень почти попал в коридоры, попробуй другой `seed`: генератор переберёт следующие 400 вариантов.

## Рисунок: что делает картинку хорошей для игры

- **Ткань — фон.** Отметь фон в `fabric`, тогда вяжется только сам рисунок. Фон светлый и спокойный, рисунок яркий.
- **Узоры, а не пятна.** Полоски, крапинки, глазки, блики и тени дают на фронте 2–3 цвета сразу, а значит выбор. Большое однотонное пятно превращает уровень в «тапни тот же цвет 5 раз».
- **Вертикальные детали важнее горизонтальных.** Фронт — это нижние клетки столбиков. Если цвета чередуются по столбцам, на фронте сразу несколько цветов. Горизонтальные полосы дают один цвет на весь ряд.
- **Слои создают риск.** Цвет, который встречается только наверху (звезда на ёлке, глаза), делает его клубки опасными в начале: они надолго займут слот.
- **Узнаваемость с 1 метра.** Картинка должна читаться в мини-плитке альбома 60×60. Проверяй силуэт.
- **Только цвета набора клубков, без оттенков.** По отзывам игроки путали оттенки одного цвета (тёмно- и светло-зелёный, оранжевый и рыжий): ставили на станок «почти тот же» клубок. Поэтому все цвета уровня, включая ткань, берутся из `YarnColors` — 12 цветов, любые два различаются с первого взгляда (ΔE2000 от 21):

  | Цвет | hex | Цвет | hex |
  |---|---|---|---|
  | Белый | `#FFFFFF` | Зелёный | `#2DB34A` |
  | Чёрный | `#26262E` | Голубой | `#4CC3F5` |
  | Серый | `#8C9198` | Синий | `#2552D9` |
  | Красный | `#E8333A` | Фиолетовый | `#B04FD8` |
  | Оранжевый | `#FF8A1F` | Розовый | `#FF6FB7` |
  | Жёлтый | `#FFD419` | Коричневый | `#8A5530` |

  Тень и блик рисуй другим цветом, а не оттенком того же: тень мишки — оранжевым при коричневом, блик — белым. LevelTool не соберёт уровень с цветом не из набора или с двумя ключами одного цвета; тесты `Level_colors_come_from_the_yarn_set` и `Colors_in_a_level_are_easy_to_tell_apart` проверяют готовые файлы.

## Кривая сложности

Уровни идут коллекциями по 5. Внутри коллекции: два обычных, один с особенностью (загадка или новая комбинация), ещё один обычный и **сложный пятый**.

| Этап | Уровни | Наугад, не выше | Бот | Чужая / лишняя пряжа |
|---|---|---|---|---|
| Обучение | 1–3 | — | 80–100% | 0–1 / 0 |
| Знакомство с механиками | 4–15 | 20–45% | 40–80% | 1–2 / 2 |
| Середина | 16–30 | 14–20% | 40–78% | 1 / 2 |
| Поздние | 31–50 | 8–14% | 40–78% | 1 / 2–3 |
| Сложные (каждый 5-й) | 5, 10, 15… | 5% | 15–45% | 1 / 2–3, часто моль |

**Слоты — по числу цветов рисунка** (без ткани): до 3 цветов — 3 слота, 4–5 — 4, 6–7 — 5, 8 и больше — 6. С меньшим числом слотов многоцветный рисунок почти непроходим.

**Чужой пряжи — одна.** Каждая взятая навсегда отнимает слот, а если она стоит перед нужным клубком, взять её приходится. Уже 2–3 штуки на 4–5 слотов превращали уровень в лотерею: бот выигрывал 0% партий. Сложность лучше давать слоями цветов, натяжением и перестановками.

**Натяжение** — 2, на картинках с 6+ цветами — 3: иначе фронт слишком узкий для такого числа цветов.

Новая механика вводится одна на уровень, с подсказкой `tip`, и первые 2–3 уровня после этого встречается в мягкой дозе.

## Шаблоны

Копируй нужный блок поверх параметров исходника и меняй под картинку.

**Обычный уровень (середина игры):**
```json
"band": 2, "slots": 4, "columns": 5, "spools": 14, "swaps": 4,
"gold": 3, "extra": 2, "junk": 1,
"minWin": 0.4, "maxWin": 0.78, "maxRandom": 0.18,
"maxForced": 0.55, "minDanger": 0.05, "maxDanger": 0.35
```

**Сложный уровень с молью:**
```json
"hard": true, "timeLimit": 120,
"band": 2, "slots": 4, "columns": 5, "spools": 16, "swaps": 6,
"gold": 4, "extra": 3, "junk": 1,
"minWin": 0.15, "maxWin": 0.45, "maxRandom": 0.05,
"maxForced": 0.55, "minDanger": 0.05, "maxDanger": 0.35
```

**Загадка:** обычный шаблон плюс `"mystery": true`. Лучше на картинке с узнаваемым силуэтом.

**Обучающий (новая механика):** обычный шаблон, `maxRandom` +0,1, `minWin` +0,1, новая механика 1–2 штуки и `tip` с объяснением.

## Новая коллекция

1. Нарисуй 5 картинок в одной теме и с общим цветом ткани (так коллекция выглядит цельной в альбоме).
2. Добавь строку в `Collections.cs`: `new CollectionInfo("Название", первый, последний)`.
3. Пятый уровень сделай сложным.
4. Обнови таблицу уровней в `docs/GDD.md`, вставив строки из вывода генератора.

Альбом, главная, карусель коллекций и награды за коллекцию подхватят её сами.

## Новая механика

1. Правило — в ядре: `LoomGame` (и, если нужно, `PictureGrid`), поле — в `LevelData`/`SpoolData`, проверка тупиков — в `LevelValidator`.
2. Тесты на правило — в `dotnet/KnittedPicture.Core.Tests`.
3. Параметр в `LevelDesign` и раскладка в `LevelGenerator` (как `AddIce`, `AddLocks`). Генератор должен ставить механику так, чтобы уровень оставался решаемым по задуманному порядку.
4. Вид в `SpoolView` / `PictureView`, отказ с понятным тостом в `GameScreen.Deny`.
5. Плашка в сцене «Особые клубки» вступления (`IntroScreen.SceneSpools`) и строка в `docs/GDD.md`.
