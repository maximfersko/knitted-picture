# Совместная работа агентов

Сначала архитектор готовит план и представляет его пользователю. После утверждения разработчик реализует изменения, затем ревьюер проверяет их; разработчик исправляет замечания, ревьюер проверяет повторно.

Роли: архитектор — gpt-6.1-sol high, разработчик — gpt-6.1-terra medium, ревьюер — gpt-6.1-sol high. Для отдельных ролей использовать native `collaboration.spawn_agent` с `fork_turns: none` и соответствующими overrides. Глобальную конфигурацию не менять.
