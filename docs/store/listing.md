# Карточка игры в магазинах

Тексты готовы к копированию. В текстах для игроков нет длинных тире, только двоеточия и запятые.

## Название

- **Google Play** (до 30 символов): `Вязаная картинка: головоломка` (29)
- **RuStore**: `Вязаная картинка`

## Краткое описание (до 80 символов)

`Свяжи пиксельную картинку из клубков пряжи. Спокойная головоломка на логику` (75)

## Полное описание (до 4000 символов)

```
Вязаная картинка: уютная головоломка, в которой ты вяжешь пиксельные картинки из клубков пряжи.

Тапни клубок, и он поедет на станок. Станок сам довязывает петли нужного цвета, ряд за рядом, пока не появится картинка: тюльпан, котик, клубничка, кит, единорог и ещё десятки других. Подумай, какой цвет нужен первым, иначе на станке не хватит места.

Что внутри:
• 50 картинок в 10 коллекциях: Сад, Зверята, Море, Небо, Праздник и другие
• Новые приёмы по ходу игры: связанные клубки, лёд, узелки, замки с ключами, толстая и радужная пряжа, картинки-загадки
• Разгон: ставь клубки без пауз, и станок вяжет быстрее
• Помощники: ножницы, лишний слот, отмена хода
• Узор дня: новая картинка каждый день и награда за серию
• Подарок дня, задания и звёздный сундук
• Коллекция пряжи: мотки с особыми бонусами и уровнями
• Без таймера на большинстве уровней: играй в своём темпе
• Работает без интернета

Спокойная, красивая и понятная игра для тех, кто любит головоломки, вязание и уют.
```

## Что нового (для версии 1.0.0)

```
Первая версия: 50 картинок, узор дня, коллекции и пряжа с бонусами.
```

## Категория, метки, рейтинг

- **Категория:** Игры → Головоломки.
- **Метки RuStore:** головоломка, вязание, пиксель-арт, логика, раскраска, расслабляющие, офлайн.
- **Возрастной рейтинг:**
  - RuStore: **0+**.
  - Google Play: заполнить анкету IARC. Насилия, азартных игр, чатов и пользовательского контента нет; реклама есть, покупка в версии для RuStore. Ожидаемый рейтинг: PEGI 3, «Для всех».
- **Целевая аудитория в Google Play** (раздел «Целевая аудитория и контент»): выбрать **13+** (13–15, 16–17, 18+). Если отметить детей до 13, включаются строгие правила семейной программы для рекламы.
- **Реклама:** «Да, приложение содержит рекламу» (в обоих магазинах).

## Google Play: «Безопасность данных» (Data safety)

Ответы для версии с рекламой Яндекса и аналитикой AppMetrica. Перед отправкой сверь с разделами про Data safety в документации Yandex Mobile Ads и AppMetrica: если SDK обновятся, состав данных может поменяться.

| Вопрос | Ответ |
|---|---|
| Собирает или передаёт ли приложение данные пользователя? | Да |
| Шифруются ли данные при передаче? | Да |
| Можно ли запросить удаление данных? | Да, письмом на e-mail поддержки |
| **Идентификаторы устройства** (рекламный ID) | Собираются и **передаются** третьей стороне (Яндекс). Цели: реклама или маркетинг, аналитика, предотвращение мошенничества. Обязательны (без них реклама не показывается) |
| **Действия в приложении** (взаимодействие с рекламой, прохождение уровней) | Собираются и передаются (Яндекс: реклама и AppMetrica). Цели: аналитика, реклама |
| **Сведения о приложении и производительности** (сбои, диагностика) | Собираются (AppMetrica). Цели: аналитика |
| **Местоположение** | Точное не собирается. Примерное: Яндекс может определять регион по IP. Если сомневаешься, отметь «Примерное местоположение → реклама» |
| Личная информация, финансы, контакты, фото, файлы | Не собираются |

## Графика

| Что | Файл | Требования |
