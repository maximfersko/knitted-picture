# Выпуск в RuStore и Google Play: по шагам

Порядок такой: сначала RuStore (быстро, деньги в рублях работают), параллельно Google Play
(закрытый тест 12 человек × 14 дней).

Что уже сделано в проекте:
- **Настройки:** имя пакета `ru.maximfersko.knittedpicture`, название «Вязаная картинка», версия 1.0.0, IL2CPP, только ARM64. **Имя пакета после первой публикации менять нельзя.** Если хочешь другое, поменяй сейчас: Project Settings → Player → Other Settings → Package Name.
- **Две сборки из одного кода:** меню **Knitted → Сборка** в Unity.
  - **RuStore:** реклама Яндекса и покупка «Без рекламы» через RuStore Pay.
  - **Google Play:** только реклама Яндекса.
- **Окно согласия на персональную рекламу** при первом запуске и переключатель в настройках. В настройках также ссылка на политику и «Восстановить покупки».
- **Покупка «Без рекламы»** выключает межуровневую рекламу. Видео за награду остаются по желанию игрока.
- **Документы:** политика конфиденциальности (`docs/privacy.html`), тексты карточек (`docs/store/listing.md`), графика (`docs/store/graphics/`), скрипт скриншотов (`tools/store/make_screenshots.py`).

---

## Шаг 1. Политика конфиденциальности

1. Открой `docs/privacy.html` и замени жёлтые поля: дату, ФИО (или ИП/компанию и ИНН) и e-mail.
2. Опубликуй страницу. Вариант с GitHub Pages: репозиторий → Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/docs`. Через минуту страница будет по адресу `https://maximfersko.github.io/knitted-picture/privacy.html`.
   - Бесплатный GitHub Pages работает только у **публичных** репозиториев. Если репозиторий закрытый, положи одну страницу `privacy.html` в отдельный публичный репозиторий или на любой сайт.
3. Если адрес получился другим, поменяй `PrivacyPolicyUrl` в `Assets/Scripts/Game/Services/Store/StoreConfig.cs`.
4. Впиши почту поддержки в `SupportEmail` там же. Пока поле пустое, строки «Написать нам» в «Настройки → Об игре» нет. Письмо открывается уже с версией игры, моделью телефона и уровнем.

## Шаг 2. Ключ подписи (один раз, навсегда)

Ключ подтверждает, что обновление выпустил ты. **Если его потерять, в RuStore нельзя будет выпустить обновление** (только новое приложение заново). Сделай 2–3 копии: облако, флешка, менеджер паролей.

В терминале, в папке проекта (нужен Java `keytool`, он есть в Unity: `…/Editor/Data/PlaybackEngines/AndroidPlayer/OpenJDK/bin/keytool`):

```bash
mkdir -p Signing
keytool -genkeypair -v -keystore Signing/knitted-upload.keystore -alias knitted \
  -keyalg RSA -keysize 4096 -validity 10000
```

Он спросит пароль (запомни!) и данные о тебе: имя, город, страну `RU`.

Создай файл `Signing/signing.json` (папка `Signing/` уже в `.gitignore`, в git не попадёт):

```json
{
  "keystore": "Signing/knitted-upload.keystore",
  "keystorePass": "ТВОЙ_ПАРОЛЬ",
  "alias": "knitted",
  "aliasPass": "ТВОЙ_ПАРОЛЬ"
}
```

Один и тот же ключ подходит для обоих магазинов. В Google Play он будет «ключом загрузки», а финальную подпись Google сделает своим ключом (Play App Signing).

## Шаг 3. Реклама Яндекса

1. Зарегистрируйся в Рекламной сети Яндекса (partner.yandex.ru), добавь мобильное приложение (Android), создай два рекламных блока:
   - **Rewarded** (видео за награду);
   - **Interstitial** (межуровневая).
2. Скопируй их ID (вид `R-M-1234567-1`) в `StoreConfig.cs`: `RewardedAdUnit` и `InterstitialAdUnit`. Пока там стоят `demo-…`: это тестовые блоки Яндекса, они показывают пробную рекламу и денег не приносят. С ними удобно проверять сборку.
3. Установи плагин: на GitHub `yandexmobile/yandex-ads-unity-plugin` → Releases → скачай `.unitypackage` → в Unity Assets → Import Package. Если Unity предложит External Dependency Manager, согласись. Затем Assets → External Dependency Manager → Android Resolver → Force Resolve.
4. Проверь: **Knitted → Сборка → Проверить, какие SDK найдены** должно показать «Реклама Яндекса: найдена».

> Код рекламы лежит в `Assets/Scripts/Game/Services/YandexAds.cs` и рассчитан на API плагина версий 6–7
> (загрузчики `RewardedAdLoader` / `InterstitialAdLoader` с событиями). Если после установки Unity
> покажет ошибки в этом файле (например, в новой версии `MobileAds` переименован в `YandexAds`),
> исправить нужно только этот файл. Остальная игра работает через интерфейс `IAds`. Пришли мне ошибки, поправлю.

## Шаг 3½. Аналитика AppMetrica

1. Зайди на appmetrica.yandex.ru тем же аккаунтом Яндекса, что и для рекламы, и добавь приложение (Android).
2. Скопируй **API key** приложения в `StoreConfig.cs` → `AppMetricaApiKey`.
3. Установи плагин AppMetrica для Unity по инструкции AppMetrica (раздел SDK → Unity), затем External Dependency Manager → Android Resolver → Force Resolve.
4. **Knitted → Сборка → Проверить, какие SDK найдены** → «Аналитика AppMetrica: найдена».

Какие события отправляет игра и какие отчёты по ним строить, описано в `docs/analytics.md`. Без плагина события
просто пишутся в Console Unity (в редакторе и в Development-сборке), так их удобно проверять.

> Код отправки: `Assets/Scripts/Game/Services/Analytics/AppMetricaSink.cs` (плагин версий 6+, `Io.AppMetrica`).
> Если имена в установленной версии другие, правки только в этом файле.

## Шаг 4. RuStore Pay (только для RuStore)

1. В консоли RuStore: Монетизация → подключи платежи (нужен статус самозанятого, ИП или юрлица и реквизиты).
2. Создай товар: тип **непотребляемый**, код **`no_ads`**, название «Без рекламы», цена на твой выбор.
3. Установи RuStore Pay SDK для Unity по инструкции RuStore (раздел SDK → Платежи → Unity). В его настройках в Unity укажи **ID приложения из консоли RuStore** и **схему deeplink** (например `knittedpicture`).
4. **Knitted → Сборка → Проверить, какие SDK найдены** → «RuStore Pay: найден».

> Код покупок в `Assets/Scripts/Game/Services/Store/RuStorePurchases.cs`. Как и с рекламой, если имена
> в установленной версии SDK отличаются, правки только в этом файле.

Без SDK игра тоже собирается: в RuStore выйдет без покупок, только с рекламой.

## Шаг 5. Сборка

В Unity: **Knitted → Сборка → …**

| Пункт меню | Что получится | Куда загружать |
|---|---|---|
| RuStore (APK) | `Builds/RuStore/knitted-picture-rustore-1.0.0-N.apk` | RuStore |
| RuStore (AAB) | то же, `.aab` | RuStore (тоже принимает) |
| Google Play (AAB) | `Builds/GooglePlay/knitted-picture-googleplay-1.0.0-N.aab` | Google Play |

При каждой сборке номер `N` (versionCode) растёт на 1: магазины принимают только номер больше прежнего. После выпуска закоммить `ProjectSettings/ProjectSettings.asset`, чтобы номер не откатился.

**Перед загрузкой проверь APK на телефоне:**
- окно «Реклама в игре» при первом заходе на главную;
- видео за награду (в окне затора или «удвоить» на победе);
- межуровневая реклама после 10-го уровня;
- в RuStore-сборке пункт «Убрать рекламу» в настройках.

## Шаг 6. RuStore

1. Зайди на **console.rustore.ru** через VK ID и выбери форму: физлицо, самозанятый, ИП или юрлицо. Для дохода от покупок нужны самозанятость, ИП или юрлицо.
2. Создай приложение: Игры → Головоломки, имя пакета `ru.maximfersko.knittedpicture`.
3. Загрузи APK или AAB из шага 5.
4. Карточка:
   - название, описания, метки — из `listing.md`;
   - значок `graphics/icon-512.png`;
   - скриншоты (шаг 8);
   - возраст **0+**;
   - ссылка на политику;
   - e-mail поддержки.
5. Отправь на модерацию. Обычно занимает до суток; если будут замечания, RuStore пришлёт, что исправить.

## Шаг 7. Google Play

1. **Аккаунт:** play.google.com/console, взнос $25. Страна в профиле, документы и карта должны совпадать. Российская карта, скорее всего, не пройдёт.
2. **Создай приложение:** «Игра», «Бесплатное». Платное приложение сделать нельзя.
3. **Тестирование → Внутреннее:** загрузи AAB и включи **Play App Signing** (предложит сам). Проверь на своём телефоне.
4. **Тестирование → Закрытое:** создай трек, добавь **не меньше 12 тестировщиков** (их Google-аккаунты или группа Google) и загрузи AAB.
   - Тестировщики должны **принять приглашение и установить игру**, и так **14 дней подряд**. Если кто-то выйдет, счётчик может сброситься, поэтому лучше позвать 15–20 человек.
5. **Политика → Содержание приложения**, заполни всё:
   - политика конфиденциальности (ссылка);
   - реклама: «Да»;
   - доступ к приложению: «без ограничений»;
   - рейтинг (анкета IARC);
   - целевая аудитория **13+**;
   - **Безопасность данных** (ответы в `listing.md`);
   - рекламный ID: **«Да, для рекламы»**.
6. **Основная страница магазина:**
   - тексты из `listing.md`;
   - значок `icon-512.png`;
   - баннер `feature-1024x500.png`;
   - 2–8 скриншотов.
7. После 14 дней: **Панель → Подать заявку на рабочий доступ** → после одобрения **Рабочая версия → Создать выпуск**.

После загрузки AAB Play Console покажет, если какой-то плагин не поддерживает страницы памяти 16 КБ («Memory page size»). Unity 6000.6 их поддерживает; если ругается на плагин, обнови этот плагин.

## Шаг 8. Скриншоты

1. На телефоне сними 4–6 экранов (без записи экрана и посторонних окон поверх игры), лучше в таком порядке:
   - уровень в процессе;
   - станок вяжет;
   - помощники (ножницы);
   - альбом с коллекциями;
   - узор дня;
   - карточка пряжи.
2. Положи их в `docs/store/raw/` как `1.png`, `2.png`, …; подписи уже в `docs/store/captions.txt`, их можно поменять.
3. `pip install pillow`, затем:

```bash
python3 tools/store/make_screenshots.py docs/store/raw docs/store/captions.txt docs/store/screenshots
```

Получишь `screenshot-1.png …` размером 1080×1920 с подписью сверху, годятся для обоих магазинов.

## Обновления

1. Подними версию: Project Settings → Player → Version (1.0.0 → 1.0.1).
2. Собери нужный вариант через меню; номер сборки вырастет сам.
3. Загрузи в консоль, впиши «Что нового» и отправь.

## Чек-лист перед первой отправкой

- [ ] Политика опубликована, ссылка открывается, в ней твои данные
- [ ] В `StoreConfig.cs` настоящие ID рекламных блоков, а не `demo-…`, и ключ AppMetrica
- [ ] Ключ создан, сохранён в 2–3 местах, `signing.json` заполнен
- [ ] APK проверен на телефоне: реклама, согласие, покупка (RuStore)
- [ ] Значок, баннер, скриншоты, тексты готовы
- [ ] Google Play: 12+ тестировщиков приняли приглашение и установили игру
