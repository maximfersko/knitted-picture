# Дизайн 2.0 (ветка `design-2.0`)

Источник: Figma «Вязаная картинка — дизайн 2.0». Экспорты лежат в `design/figma-2.0/`:
экран уровня, основы, иконки, клубки, компоненты, игровые объекты, мета.

## Что сделано

**Полотно на спице (`Views/KnitBoard.cs`)** заменило сетку клеток на экране уровня.
- Деревянная доска, на ней бумажная схема: название картинки, «ряд N из H», номера рядов, бледные клетки будущих рядов.
- Под спицей настоящее полотно из лицевых петель с кручёной нитью, ворсом и швом между дольками.
- Спица стоит над самым высоким рядом. У столбиков, которые до неё дошли, на спице живые петли. Отстающие столбики показывают свои клетки схемы. Следующая петля каждого столбика отмечена пунктирной рамкой, которая тихо дышит.
- Камера:
  - картинка помещается целиком: она стоит по центру, а спица поднимается ряд за рядом;
  - высокая картинка: полотно свисает со спицы, над спицей видно три ряда схемы;
  - самый отстающий столбик всегда остаётся в кадре.

**Анимация вязания** (тайминги в `KnitBoard` и `YarnRopes`):
1. **Рабочая нить** (`Views/YarnRope.cs`, `Views/YarnRopes.cs`):
   - у каждого вяжущего клубка своя кручёная нить (меш по сплайну Катмулла — Рома);
   - маршрут: от клубка под доску, вдоль низа к ближнему к петле углу, вверх по краю, над спицей дугой к петле;
   - конец нити догоняет петлю пружиной (ω = 26, без дрожи);
   - витки бегут к спице, натяг петли выпрямляет дуги;
   - когда клубок кончился, нить сматывается обратно.
2. **Петля** через 0.1 с соскальзывает со спицы на своё место за 0.22 с: out-back, на лету вытянута (1.25), на посадке сплющена (0.9).
3. **Ткань и спица реагируют:**
   - две петли ниже в столбике подтягиваются и отпускают;
   - спица кивает на пружине;
   - столбик, дошедший до спицы, накидывает на неё живую петлю.
4. **Ряд закрыт:** по нему пробегает волна. Номер ряда в шапке подпрыгивает.
5. **Победа:** спица уезжает вправо, полотно отъезжает, чтобы картинка была видна целиком, потом по рядам снизу вверх идёт волна.

**Экран уровня:**
- шапка: пауза, «Уровень N» (у сложного — красная с молнией), монеты;
- фиолетовая полоса времени, моль сидит на её конце и идёт влево; без моли эта полоса показывает прогресс и процент;
- плашка «Комбо ×N» и «Разгон» на кромке доски;
- деревянный станок с выточенными лунками и спицами; лунки светятся оранжевым (последнее место), красным (мест нет) и золотом («Разгон»);
- поле без карточки: передний ряд внизу, у большого пальца; задние ряды выше, меньше и пастельные;
- бустеры — белые карточки с цветными иконками и бейджами (количество, «даром», цена);
- выноски тёмные со строчкой, кольца затора пунктирные;
- раскладка отдаёт доске ровно столько места, сколько нужно картинке; лишнее идёт клубкам и зоне большого пальца.

**Клубки** (`Art/BallRaster.cs`, `Views/SpoolView.cs`):
- глянцевая намотка, ворс, завиток, тень;
- накладки: лента связки с бантиком, замок на ремешке, ключик, узелки, ледяной пузырь (трещин больше, когда льда меньше), «?» в бумажной обёртке;
- бирка числа петель со строчкой.

**Набор интерфейса:**
- строчка на кнопках;
- белый тост;
- токены палитры 2.0 (`Warn`, `Berry`, `Brass`, `Felt`, `Shade`, `Bounce`, `Night`, `IceFill`, `IceRim`, `Table`);
- текст паузы «Картинка подождёт. Моль тоже.».

**Мета** (`Art/MetaRaster.cs`):
- ягодная вязаная шкатулка с латунным замком;
- подарок в вязаной коробке;
- монета с клубком;
- деревянные пяльцы с латунным винтом;
- картинки в пяльцах и в альбоме — вязаные миниатюры из петель;
- строчка цвета редкости на карточке пряжи.

## Как проверять без Unity

Вся графика 2.0 рисуется кодом на чистом C# (`Assets/Scripts/Game/Art/*Raster.cs`, без ссылок на движок).

```bash
dotnet run -c Release --project dotnet/KnittedPicture.ArtPreview -- OUT          # спрайты и листы в PNG
python3 tools/design/screen_mock.py OUT/sprites mock.png                         # макет экрана уровня
python3 tools/design/knit_anim.py OUT/sprites anim                               # анимация вязания, anim/knit.mp4
```
