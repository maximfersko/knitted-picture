# Вязаная картинка

Hybrid-casual головоломка: игрок отправляет клубки на станок, станок сам вяжет пиксельную картинку ряд за рядом. Движок — Unity 6 LTS, 2D.

## Структура

| Путь | Что там |
|---|---|
| `Assets/Scripts/Core/` | Правила игры без Unity: станок, поле, бустеры, проверка и решатель уровней |
| `Assets/Resources/Levels/` | Уровни в JSON, `level_001.json` и дальше |
| `dotnet/` | Сборка ядра вне Unity и тесты на xUnit |
| `.github/workflows/core-tests.yml` | Тесты ядра на каждый push |

Ядро не зависит от Unity (`noEngineReferences` в `KnittedPicture.Core.asmdef`), поэтому его можно проверять тестами без редактора. Вид (спрайты, анимации, тапы) будет отдельной сборкой поверх ядра.

## Правила в ядре

- Картинка вяжется с нижнего ряда, каждый ряд слева направо. Каждая петля берёт 1 единицу нитки из клубка своего цвета.
- Тап по колонке отправляет передний клубок в первый свободный слот. Станок вяжет, пока на нём есть нужный цвет.
- Пустой клубок освобождает слот.
- Затор: все слоты заняты, а нужного цвета на станке нет.
- Бустеры: `AddSlot` (+1 слот, снимает затор), `PullSpool` («Ножницы» — достать клубок с любой глубины колонки), `Undo` (отмена хода; купленный слот остаётся).

## Формат уровня

```json
{
  "id": 1,
  "width": 6,
  "height": 6,
  "colors": ["#6CB8FF", "#FF6FA5"],
  "picture": ["010010", "111111", "111111", "011110", "001100", "000000"],
  "slots": 5,
  "spools": [
    { "column": 0, "color": 0, "loops": 8 },
    { "column": 1, "color": 1, "loops": 10 }
  ]
}
```

- `picture` — ряды сверху вниз, цифра — индекс цвета в `colors` (до 10 цветов).
- `spools` — клубки на поле. Внутри колонки первый в списке — передний.
- Петель в клубках каждого цвета должно быть ровно столько, сколько клеток этого цвета в картинке. Это проверяет `LevelValidator`.
- Каждый уровень должен проходиться без бустеров. Это проверяет `LevelSolver` в тестах.

В Unity уровень читается так: `JsonUtility.FromJson<LevelData>(Resources.Load<TextAsset>("Levels/level_001").text)`.

## Как открыть в Unity (Mac на M1)

1. Unity Hub → Installs → Unity 6 LTS с модулями Android Build Support и iOS Build Support.
2. New project → шаблон **Universal 2D** → создать во временной папке.
3. Скопировать из неё в корень репозитория папки `Packages/` и `ProjectSettings/`.
4. Unity Hub → Add → Add project from disk → папка репозитория.
5. Unity создаст `.meta`-файлы для скриптов и уровней — их нужно закоммитить.

## Тесты ядра

Нужен .NET 8 SDK (`brew install --cask dotnet-sdk` на Mac).

```bash
dotnet test dotnet/KnittedPicture.Core.Tests
```

Ядро собирается под `netstandard2.1` и C# 9 — как в Unity, поэтому то, что прошло тесты, скомпилируется и в редакторе.
